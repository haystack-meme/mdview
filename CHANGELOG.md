# Changelog

## 0.1.0 (2026-11-26)

First release.

- Markdown viewer: GitHub-style Markdown with syntax highlighting, follows the system light/dark theme.
- Per-window edit mode with rich-text (Milkdown) and plain-text editors.
- One window per file, single app instance, reload on external changes.
- Linux packages: AppImage, .deb, tar.gz.
